
# 🎬 Netflix Content Analysis — Power BI

## 📌 Project Overview

I worked on this project to explore Netflix's content using **Power BI**. The analysis looks at movies and TV shows, genres, ratings, countries, content trends, and other useful patterns in the dataset.

The project covers **data cleaning, transformation, DAX measures, and visualization**.

## 🛠️ Tools Used

* Power BI
* Power Query
* DAX
* CSV Dataset

## 🔍 Data Cleaning & Transformation

The dataset was cleaned and prepared in Power Query by:

* Removing duplicates and unnecessary rows
* Handling missing values
* Cleaning and trimming text
* Changing data types
* Extracting year and month from `date_added`
* Preparing fields such as genres, countries, directors, and cast for analysis

## 📊 Key Insights

* **Movies** make up a larger share of Netflix's content than TV Shows.
* Netflix's content growth became more noticeable **after 2015**, with some years showing a significant increase in additions.
* **Dramas, Comedies, and International Movies** are among the most common categories.
* The **USA and India** contribute a large number of titles, while countries such as **Japan, South Korea, and the UK** also have strong representation.
* **TV-14 and TV-MA** are among the most common ratings in the dataset.
* Most Netflix movies fall within the **80–120 minute** duration range, with a few longer outliers.
* Director and cast analysis helps identify **frequently appearing talent** across Netflix content.
* Monthly analysis highlights **patterns in when content is added** throughout the year.
* The Genre vs Country analysis shows how **content varies across different regions**.
* The searchable Title Explorer makes it easy to find a title and view details such as **director, cast, rating, duration, and genre**.

## 📈 Project Outcome

This project turned raw Netflix data into an **interactive Power BI dashboard**, making it easier to explore the content library and find useful patterns and trends.
